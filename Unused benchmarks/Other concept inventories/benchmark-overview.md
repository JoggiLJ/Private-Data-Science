# Other Concept Inventories

This folder is a survey of concept inventories beyond FCI/BCI/CINS (which have their own folders) — assessment instruments that test conceptual understanding rather than factual recall, across biology, chemistry, math, physics, and astronomy.

The source is `concept-inventories.pdf`, a catalog (ASBMB) listing ~65 named instruments with references — a bibliography, not a question bank in itself. For each listed instrument, `2026-07-03-concept-inventories-overview.md` records whether the actual items were locatable (openly published, gated behind educator registration, paywalled, or not found), and `2026-07-03-concept-inventories-question-sets.md` / `Question sets/` contain the ones that could be transcribed (e.g. DODT, Basic Tree Thinking, ADT). `JSON_set/` holds the structured versions of those transcribed sets.

See `2026-07-03-concept-inventories-overview.md` for the full instrument-by-instrument breakdown.
